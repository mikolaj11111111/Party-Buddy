# Sources for 5 Seconds prompt dataset

Dataset files:

- `prompts.json`

The 5 Seconds prompt batch was locally authored in Polish for Party Buddy.
Prompts, categories, sample answers, and difficulty labels are original local text.

The `sample_answers` values are examples for future UI/testing and are not a
closed answer key. The game is intended to ask players to name any valid three
items matching the prompt.
